# PowerChain Marketplace v1.6.0

Independent public Next.js discovery surface for renewable energy, infrastructure, community and tokenized real-world launches. It shares PowerChain brand/UI packages but remains a separate client bundle from the operator Launch OS.

The Marketplace may consume public launch and market endpoints only. Auth, Helius, database and provider secrets remain on the API service.

Cloudflare Workers preview/deploy scripts are provided through OpenNext + Wrangler.
