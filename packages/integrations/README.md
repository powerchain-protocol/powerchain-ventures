# @powerchain/integrations

Server-safe provider and protocol integrations for PowerChain Launchpad 1.0.0.

Current modules include Helius, Pyth, Birdeye, CoinMarketCap, amount/rate helpers, Circle CCTP V2 status, and capability-gated ZK Compression metadata.

Credentials remain server-only. Protocol metadata in this package does not automatically activate a checkout payment rail; activation is controlled through the PowerChain payment configuration.
