# @powerchain/components

Shared PowerChain brand and shadcn-compatible primitives used by the frontend and marketplace.

Exports include:

- `Logo`, PowerChain icon set
- `Button`, `Card`, `Dialog`
- `Badge`, `Input`, `Progress`, `Skeleton`, `Separator`
- `DropdownMenu`, `Tooltip`, `Tabs`

The package contains component behavior only. App theme CSS owns visual tokens, allowing the same components to work on white, dark and forest-green surfaces without forcing either Next.js app into the other's bundle.
