# UI Primitives

Reusable UI controls live in:

```text
apps/frontend/components/ui/
```

Core components:

- `button.tsx`
- `card.tsx`
- `tabs.tsx`
- `badge.tsx`
- `select.tsx`
- `dropdown.tsx`
- `forms.tsx`
- `form-field.tsx`

Auth, contact, checkout and navigation compose these controls instead of
reimplementing focus, dropdown, badge, form-grid and responsive behavior.
